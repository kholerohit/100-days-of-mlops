# 100 Days of MLOps

This repository contains the complete set of daily tasks and reference solutions for the KodeKloud 100 Days of MLOps challenge.

## Overview

- 100 day-by-day MLOps exercises
- one folder per task
- each folder includes a task description and a solution walkthrough
- [Practical, topic-organized MLOps knowledge guide](knowledge.md)
- direct task links are included below for fast navigation

├── ...
