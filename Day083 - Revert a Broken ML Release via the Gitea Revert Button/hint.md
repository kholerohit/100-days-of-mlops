# Hint: Revert a Broken ML Release via the Gitea Revert Button

## Topic and approach

A UI-driven revert creates a new change that reverses the selected commit; it does not erase history. Identify the exact bad release commit, verify the revert diff, and run the normal checks on the resulting state.

## Work independently

Use this as a starting point, then confirm the task requirements and validate the resulting state before consulting the solution.
